# Marca de Shifty

`shifty-icon-source.png` es el original aportado para el icono. SHA-256:
`1B39B405D77238E1A50FFFBE81717FABE0B8B907FABB58DA8866C48C8BF67AF6`.

Los cuatro PNG de `frontend/public` son exportaciones reducidas de ese original,
sin alterar el diseño. La tarjeta `frontend/public/og-shifty.jpg` reutiliza esa
marca y se exportó a 1200 × 630, conservando la proporción y completando el
margen con negro. JPEG calidad 90, 65.949 bytes.
